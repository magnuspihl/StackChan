StackChan kit

Install the kit firmware on an M5Stack StackChan and set it up, from this page. Everything runs in your browser and talks to the robot over the USB cable. Nothing you enter here is sent anywhere else.

This browser can't talk to USB devices. Use Chrome or Edge on a computer (not a phone).

Before you start

With this firmware the robot calls the speech and AI services itself, over your Wi-Fi. There is no server to run.

Your API keys are stored on the robot, unencrypted. Anyone who has the robot in their hands can read them out. Treat it like a phone that is logged in; use keys with a spending limit.

What you say goes to the providers you pick: your voice to the speech-to-text service, the conversation and any photos you ask for to the AI model, its replies to the voice service. Nothing goes to M5Stack or China.

1. Connect

Plug the robot into this computer with a USB-C data cable, switch it on, then pick it in the list (it shows up as "USB JTAG/serial debug unit" or similar).

2. Install the firmware

Skip this if the kit firmware is already on the robot and you only want to change settings.

Restore a backup

Puts a backup from step 2 back on the robot: the factory firmware if it was your first backup. This replaces everything on the robot, kit firmware and settings included.

A backup also holds the robot's Wi-Fi password and any API keys that were on it when it was made. Keep the file private.

3. Settings

Empty fields keep what the robot already has. You can come back and change settings any time; plug the robot in and use only this step.
